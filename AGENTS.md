# Обязательные правила работы с проектом

- Перед изменениями прочитать `PROJECT.md` и учитывать текущий план разработки.
- Выполнять только явно запрошенный этап; после проверки обновлять его статус и останавливаться.
- Перед написанием кода кратко описать подход.
- Не менять и не рефакторить несвязанный код.
- Не придумывать отсутствующие API, данные и требования.
- Использовать только HTML, CSS и JavaScript без сервера, базы данных и фреймворков, пока не согласовано иное.
- Сохранять полностью русский пользовательский интерфейс.
- Поддерживать адаптивность, доступность и умеренные анимации.
- Сохранять данные эпох отдельно от интерфейса и игровой логики.
- Для статических представлений 1957 использовать `assets/sputnik-1957-static-reference.png`; интерактивный Спутник-1 держать отдельным управляемым объектом и не встраивать в фон сцены.
- Новую эпоху добавлять преимущественно через данные, без переписывания ядра.
- Генерировать задания из событий; не хранить вручную вопросы, которые можно получить из данных.
- Сохранять ошибки по идентификаторам событий и использовать их для более частого повторения.
- Не наказывать за ошибки во время обучения и тренировки; жизни использовать только в финальном испытании.
- После изменений проверять основной пользовательский путь и отсутствие новых ошибок.
