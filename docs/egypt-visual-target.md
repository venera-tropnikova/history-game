# Египет — целевая визуальная концепция

Статус: **принята**. Код и механику не менять, пока не начат этап конкретной сцены. Изображения не генерировать и placeholders не подменять без указания.

## Принцип

Египет — экспедиция в мире «Карты времени», не школьный слайд.

- Крупный кадр + одна фраза + крупное действие (как миссии динозавров).
- Палитра: песок, золото, лазурь Нила, тёмный индиго.
- Один ясный объект на экране. Без декоративного шума и текста на картинке.
- Стиль: насыщенная иллюстрация уровня карты и динозавров.
- Детям 7–11: без ужаса в сцене мумии, тёплый свет.

Сетка экрана сверху вниз: кадр → заголовок → одна фраза → действие. Назад/вперёд внизу, не спорят с картинкой.

Герой сцены: **1920×1080, 16:9**, объект в центре. На телефоне тот же кадр кропается (объект крупный). Плитки предметов: **512×512** PNG с прозрачностью.

## Порядок сцен (строго по одной)

Следующий этап начинается только после визуального PASS предыдущей.

1. **intro-giza** — вступление  
2. Внедрение слота + визуальная проверка  
3. PASS → следующая сцена

Дальше, не раньше PASS intro:

4. Нил (`nile-dry` / `nile-water` / `nile-flood`)  
5. Пирамиды (`giza-plateau` + блоки)  
6. Иероглифы (`papyrus-desk` + 4 знака)  
7. Фараон (`tomb-chamber` + 3 предмета)  
8. Награда (`reward-giza`)  
9. Проверка — без нового героя, миниатюры из кадров миссий

## Сцены

### Вступление — intro-giza
- Фон: закат над плато, индиго в тенях, золото на камне.
- Объект: три пирамиды Гизы, чуть правее центра; Нил блестит далеко слева.
- Текст: «Тайны Древнего Египта» + одна фраза про 4–5 тысяч лет.
- Действие: кнопка «Начать экспедицию».
- Файл: `assets/egypt/intro-giza.png` · 1920×1080 · PNG без надписей.

### Миссия 1 — Нил
- Фон: та же долина, камера ниже, лазурное небо.
- Объект: река через кадр (сухая → полноводная → поля).
- Текст: статус шага, одна строка.
- Действие: нажатие по реке / разлив, затем выбор.
- Файлы: `nile-dry.png`, `nile-water.png`, `nile-flood.png` · 1920×1080 · одна камера.

### Миссия 2 — Пирамиды
- Фон: плато днём. Объект: Хеопс в центре, две соседние меньше.
- Текст: собери → зачем → когда Хеопс.
- Действие: 3 блока, затем выборы.
- Файлы: `giza-plateau.png` 1920×1080; `block-base.png` 640×240; `block-mid.png` 480×200; `block-cap.png` 320×280 (PNG, прозрачный фон у блоков).

### Миссия 3 — Иероглифы
- Фон: папирус на камне. Объект: 4 крупных знака.
- Текст: «знак, затем смысл»; потом вопрос про папирус и камень.
- Действие: сетка знаков и смыслов.
- Файлы: `papyrus-desk.png` 1920×1080; `glyph-sun|water|bird|house.png` 512×512.

### Миссия 4 — Фараон
- Фон: индиго камеры, золотой свет. Объект: саркофаг в центре.
- Текст: кто фараон → шаг обряда.
- Действие: выборы, затем 3 карточки.
- Файлы: `tomb-chamber.png` 1920×1080; `obj-mummy|sarcophagus|tomb.png` 512×512.

### Награда
- Фон: тот же закат, ближе к Хеопсу, больше золота.
- Текст: «Экспедиция завершена!» + одна фраза-итог.
- Действие: ещё раз / на карту.
- Файл: `reward-giza.png` 1920×1080. Пока нет файла — допустим кроп `intro-giza`.

### Проверка
Отдельный герой не нужен. Миниатюры: `nile-flood`, `giza-plateau`, папирус/знаки, гробница.

## Повторное использование

- `intro-giza` → награда, если нет `reward-giza`.
- `nile-flood`, `giza-plateau`, `papyrus-desk`, `tomb-chamber` → иконки проверки.
- Блоки пирамиды и знаки — только в своих миссиях.
- Персонажа с карты не тащить, пока нет согласованного героя Египта.
